# 개인정보 보호 안내

타임라인 비주얼라이저는 사용자가 선택한 `Timeline.json`을 휴대전화 안에서 읽고,
미리보기와 MP4 영상을 기기 안에서 생성합니다.

## 앱이 접근하지 않는 정보

- 현재 위치 또는 백그라운드 위치
- Google 계정과 연락처
- 선택하지 않은 파일과 폴더
- 광고 식별자와 분석 데이터

앱은 위치, Google 로그인, 전체 저장공간 권한을 요청하지 않습니다. JSON 파일은
Android 시스템 파일 선택기를 통해 사용자가 직접 선택합니다.

## 지도 타일 요청

배경 지도를 표시하기 위해 CARTO 서버에서 OpenStreetMap 기반 지도 타일을 받습니다.
이 요청에는 화면에 보이는 지도 영역을 나타내는 타일 번호와 일반적인 네트워크 정보가
포함될 수 있습니다. 전체 Timeline JSON과 영상 프레임은 CARTO로 전송되지 않습니다.

불러온 JSON은 앱 전용 저장공간에 복사하지 않습니다. 생성한 MP4는 사용자가 선택한
위치에 저장되며, 앱의 캐시나 데이터를 삭제하면 임시 지도 타일도 삭제됩니다.
